# Roadmap

The maintained roadmap lives in **[docs/ROADMAP.md](docs/ROADMAP.md)** — milestones, current state, and
the contributor-ready backlog.

Proposing a roadmap change: open an issue using the RFC template in [GOVERNANCE.md](GOVERNANCE.md).
Anything that changes a public contract (ContribSpec fields, rule ids, report schema, CLI flags) needs
that RFC before implementation.

Current milestone: **0.1 — usable locally** (implemented, pre-release).
